# NoteLens User Manual

Open [NoteLens](https://notelens-live-production.up.railway.app/) in your browser.

> NoteLens is an educational tool and does not replace a doctor. Use only public or synthetic documents written in English. Do not upload real personal medical reports.

## Open a report

- **Built-in example.** Under **Choose an example**, select **Chest pain report**. Wait for **Report overview**.
- **Pasted text.** Under **Paste English text**, paste your report, choose **Public material** or **Synthetic example**, and select **Open pasted text**.
- **PDF.** Under **Upload a text-based PDF**, choose a file with selectable text, select its source, and click **Open PDF**. The file must be 2 MiB or smaller.

## Read the results

**Canonical document** shows the text NoteLens uses. **Document specialty** shows the suggested specialty or **Specialty uncertain**. Review **Document findings** and **Document summary**, then select **View passage** to highlight the source text.

## Ask a question

In **Questions and literature**, choose an option from the **Source** menu, enter your question, and select **Ask question**.

- Choose **Document** to ask about the open report. Try "What does the document say about chest pain?"
- Choose **Literature** to ask a general medical question. Try "What does MedlinePlus say about asthma symptoms?"
- Choose **Both** to ask two questions. Enter one about the report in **Document question** and a general question in **Literature question**.

Open **Try a preset question** to see the suggested questions.

## Check the evidence

Select **View document evidence** to check the quoted passage. Select **Literature source URL** to open the original source. **Partial evidence** means the answer covers only part of your question. **Insufficient evidence** means the available sources do not support an answer.

## If you get stuck

- **PDF rejected?** Make sure the document is written in English and has selectable text. For a scan, paste the report text instead.
- **Document unavailable?** Reopen the example or submit the document again. NoteLens stores documents in server memory for up to 60 minutes.
- **Clearing saved questions.** Select **Clear conversation history** when it appears.
